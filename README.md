# 展示实体编辑器

## 使用前准备

将模组放入 Minecraft 1.20.1 Forge 的 mods 文件夹并启动游戏。

进入游戏后，可在创造模式的“工具与实用物品”分类中找到“展示实体编辑器”，也可以使用命令：

`/give @s examplemod:display_entity_editor`

## 选择展示内容

1. 手持“展示实体编辑器”。
2. 按 `G` 打开“选择展示类型与内容”菜单。
3. 选择方块、物品或文本展示实体。
4. 方块和物品可以通过名称或资源 ID 搜索；文本可直接输入。

选中的展示类型和内容会继续用于之后的放置，直到再次打开菜单修改。

## 放置与选择

- 手持编辑器右键方块表面：在相邻空间放置当前选择的展示实体。
- 左键展示实体：选中实体，不会将它破坏；选中后会显示绿色边框。
- 右键展示实体：打开右下角编辑面板。

## 选择过滤组

未打开实体编辑面板时，可以使用选择组过滤左键能够选中的展示实体。默认共有 9 组，当前组和过滤模式会显示在 HUD 左上角。

- `Shift + 鼠标滚轮`：切换当前选择组。
- `Alt + Q`：在 EXCLUDE 和 ONLY 模式之间切换。
- EXCLUDE：普通左键只能选择不在当前组中的实体；`Alt + 左键`把实体加入当前组。
- ONLY：普通左键只能选择当前组中的实体；`Alt + 左键`把实体移出当前组。

需要修改选择组数量时，可编辑游戏目录下 `config/examplemod-client.toml` 中的 `selectionGroupCount`。

## 编辑模式

按 `V` 在“数值模式”和“视图模式”之间切换。快捷键都可以在“选项 → 控制 → 按键绑定 → 展示实体编辑器”中修改。

### 数值模式

可直接输入：

- 位置 X / Y / Z
- 旋转 X / Y / Z
- 缩放 X / Y / Z

输入后点击“应用”保存修改；“重置”恢复默认数值；“关闭”退出编辑。

### 视图模式

视图模式不会修改实体位置，只能调整缩放和旋转。

- 按住 `Shift` 并滚动鼠标滚轮，在“缩放模式”和“旋转模式”之间切换。
- 拖动右下角的 X、Y、Z 滑块实时调整展示效果。
- 再次按 `V` 可返回数值模式。
